# Склерозник — iOS-приложение напоминаний

Личное приложение для напоминаний с локальными уведомлениями. Не публиковалось в App Store.

## Что умеет

- Локальные push-уведомления через UserNotifications
- Повторы: каждый день, неделю, год
- Разделы «Будущие» и «Прошедшие» напоминания
- Экспорт и импорт напоминаний в JSON (замена или объединение)
- Выбор нескольких дат в календаре

## Стек

- Swift, SwiftUI
- UserNotifications
- iOS 17+

## Как запустить

1. Откройте `склерозник.xcodeproj` в Xcode.
2. Выберите симулятор iPhone.
3. Нажмите Run (⌘R).
